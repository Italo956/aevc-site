Política de Privacidade do AEVC Studio

Última atualização: 22 de novembro de 2026

O AEVC Studio é um programa de uso interno, instalado e executado nos computadores da nossa equipe. Ele é usado para produzir vídeos e, com autorização, enviá-los aos canais do YouTube que pertencem à equipe ou que ela administra.

Quais dados o programa acessa

Quando o dono de um canal conecta a sua Conta Google ao programa, o AEVC Studio pede somente estas permissões:

  • Enviar vídeos ao YouTube (youtube.upload): para publicar no canal os vídeos que a equipe revisou e aprovou.
  • Ver informações do canal (youtube.readonly): para mostrar o nome e a foto do canal conectado e confirmar que o vídeo vai para o canal certo.

O programa não lê e-mails, contatos, arquivos do Google Drive nem qualquer outro dado da Conta Google.

Como os dados são usados e guardados

  • A autorização (token de acesso) fica guardada apenas no computador da equipe onde o canal foi conectado.
  • Os dados são usados exclusivamente para enviar os vídeos aprovados e exibir o nome do canal dentro do programa.
  • Não vendemos, não compartilhamos e não transferimos dados de usuários do Google a terceiros.
  • Não usamos os dados para publicidade nem para treinar modelos de inteligência artificial.

Uso limitado

O uso e a transferência, para qualquer outro aplicativo, das informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. O programa também segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Como remover o acesso

O dono do canal pode desconectar o canal dentro do AEVC Studio a qualquer momento (o token é apagado do computador) ou remover o acesso direto na Conta Google, em myaccount.google.com/permissions.
